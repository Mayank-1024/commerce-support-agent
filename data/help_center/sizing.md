# Sizing

## Apparel sizing
Our tops and outerwear run true to size. If you are between sizes, size up for layering. Each product page lists chest, waist and length measurements.

## Footwear sizing
Our footwear uses US sizing. The canvas sneaker runs half a size large; the hiking boot runs true to size with room for a hiking sock.

## Pants and denim
Bottoms are sized by waist in inches. Raw selvedge denim stretches about half an inch at the waist with wear.
